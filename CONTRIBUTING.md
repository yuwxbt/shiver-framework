# Contributing

Use Node 22.12 or later and run `npm ci`. Keep the ESM source, public declarations in `types/`, and examples in sync. Run `npm run check` before opening a pull request. Test behavioral changes offline and document them in `docs/`. The website renders those same Markdown files.

Keep changes focused and avoid adding runtime dependencies. Report security issues through the private route in [SECURITY.md](SECURITY.md).
